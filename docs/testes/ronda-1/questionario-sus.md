# Questionário SUS (System Usability Scale)

> **Integridade:** a versão portuguesa validada é a de Martins *et al.* (2015), citada na base de UX (9.5).
> O texto abaixo é uma **tradução de trabalho** dos 10 itens de Brooke (1996), feita para este projecto.
> **[CONFIRMAR]** Antes de aplicar, substituir pelo texto exacto da versão validada (Martins *et al.*, 2015), para
> os resultados serem comparáveis e citáveis no Capítulo IV.

Para cada afirmação, marque de 1 (discordo totalmente) a 5 (concordo totalmente), pensando na plataforma que acabou
de usar.
