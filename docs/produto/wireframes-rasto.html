Como ler

Cada quadro está desenhado no tamanho alvo

Telemóvel a 360 px e computador a 1280 px (o quadro de computador rola na horizontal em ecrãs estreitos). O código final aplica md: (768) e lg: (1280) sobre a mesma marcação. As cores vêm só de rasto.css; mude o tema no botão acima para ver o modo escuro. O código de cada quadro na especificação (ex.: E-07) é o mesmo da lista de ecrãs.
