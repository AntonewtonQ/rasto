# docs/relatorio/

Relatório do TCC gerado a partir de `src/`. Para gerar: `./build.sh` (precisa de Python 3 com `python-docx` e `matplotlib`; o LibreOffice é opcional e serve para os números de página do índice e para o PDF de verificação; o Graphviz só é preciso para regenerar diagramas `.dot`).

- `TCC_Rasto.docx`: resultado (não editar à mão).
- `src/`: texto e montagem. `figuras/`: imagens e os seus ficheiros-fonte. `dados/`: agregados do inquérito, sem dados pessoais. `modelo/`: estilos do exemplo do ISPTEC e logótipo.
- `DECISOES.md`: decisões e sincronizações. `PENDENTES.md`: marcadores por resolver.
- `indice-tcc-rasto.md`: índice detalhado aprovado (planeamento das secções, figuras e fontes).
